Tutorial

Instalação do Claude Code.

Passo a passo do zero. Escolhe teu sistema operacional abaixo. Em 8 a 12 minutos tu sai com tudo instalado e autenticado.

Pré-requisitos no Mac

Antes de instalar o Claude Code, é necessário ter o Node.js. Se tu nunca mexeu com ferramentas de desenvolvimento, provavelmente não tem ainda.

Baixa o instalador do macOS no site oficial: nodejs.org/pt/download — executa normalmente.

01
Instalar Claude Code via terminal

Abre o terminal usando Command + Espaço e digitando "terminal". Cola:

$ npm install -g @anthropic-ai/claude-code

Pressiona Enter e confirma com Y quando solicitado. Depois testa:

$ claude --version
02
Instalar o VS Code

Baixa do site oficial: code.visualstudio.com

Ao abrir pela primeira vez, fecha qualquer chat lateral que aparecer. O VS Code é onde tu vai rodar o Cockpit.

03
Instalar a extensão do Claude Code

No VS Code, clica no ícone de extensões (quadradinhos na barra lateral esquerda).

Procura por "Claude Code" e instala a versão oficial da Anthropic.

Atenção

Tem versões falsas com nome parecido. Confirma que o autor é Anthropic.

04
Autenticar

Usa a barra de comandos (Cmd + Shift + P) e digita "Claude Code". Escolhe "abrir em nova aba".

Na primeira vez, clica no botão azul de autenticar. O navegador abre pra tu autorizar a conexão com tua conta Claude.

Conta necessária

Claude Code funciona apenas com contas Claude Pro ou superiores (a partir de US$ 20/mês).

01
Baixar e instalar o VS Code

Baixa o instalador direto do site oficial: code.visualstudio.com

Roda o instalador, aceita os padrões, finaliza. Abre o VS Code.

02
Instalar a extensão Claude Code

No VS Code, clica no ícone de extensões (quadradinhos na barra lateral esquerda).

Procura por "Claude Code" e instala a versão oficial da Anthropic.

Atenção

Tem várias extensões com nome parecido. Confirma que o autor é Anthropic antes de instalar.

03
Autenticar

Abre a barra de comandos (Ctrl + Shift + P) e digita "Claude Code". Escolhe "abrir em nova aba".

Clica no botão azul de autenticação. O navegador vai abrir pra tu autorizar a conexão com tua conta Claude.

04
Confirmar instalação

Com tudo conectado, digita um comando teste no chat. Se respondeu, tá funcionando.

Conta necessária

Claude Code funciona apenas com contas Claude Pro ou superiores (a partir de US$ 20/mês).
