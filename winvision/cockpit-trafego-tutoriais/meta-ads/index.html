Tutorial

Conectando o Meta Ads ao Claude Code.

Passo a passo do App no Meta Developers, System User Token, BM e conta de anúncios. O Claude conduz pelo chat. Esta página é tua referência visual.

Antes de começar

Esse é o tutorial mais longo do curso, mas é uma vez só. Depois de configurado, qualquer cliente novo é só compartilhar a conta — não precisa refazer App ou Token.

Como vai funcionar

Tu não precisa decorar nada. Rode /cockpit-meta-ads setup no Claude e ele vai te perguntando o que precisa. Esse tutorial aqui é pra tu acompanhar e ter referência visual.

Tudo via chat — começa assim

> /cockpit-meta-ads setup ✓ Vou te guiar pra conectar o Meta Ads. ✓ Primeiro precisamos criar um App no Meta for Developers. ✓ Já tem App criado ou começamos do zero?

A partir daí, segue o que ele pedir. Cada passo abaixo corresponde a uma orientação que o Claude vai te dar.

Os 12 passos da integração

01
Entrar na conta do Meta Developers

Acessa developers.facebook.com e faz login com a conta do Facebook que vai administrar o App.

Se nunca usou o Meta for Developers, ele vai pedir verificação rápida (telefone).

02
Criar o aplicativo

Clica em My Apps no canto superior direito → Create App.

03
Selecionar tipo: Empresa (Business)

Caso de uso: Other → Tipo: Business.

Isso libera as APIs de marketing que tu precisa.

04
Dar nome ao aplicativo

Nome: algo descritivo, ex: Cockpit Tráfego Geral ou Cockpit [Sua Agência].

Email de contato: o teu.

Portfólio comercial: seleciona a BM dona do App.

Arquitetura resiliente (importante)

Cria o App numa BM com pelo menos 3 admins humanos. NUNCA na BM de cliente (se perder o cliente, perde o App). Nunca em BM com 1 admin só (se o perfil cair, ninguém acessa).

05
Adicionar o produto Marketing API

No painel do App, menu lateral → Add Product.

Procura Marketing API e clica em Set Up.

06
Confirmar que tá habilitado

Marketing API ficou listada no menu lateral do App. Pronto pra próxima etapa.

07
Entrar na BM (Business Manager)

Acessa business.facebook.com/settings.

Confirma que tu tá na BM certa (a mesma onde criaste o App).

08
Usuários → Usuários do Sistema

Menu lateral: Users → System Users.

09
Criar um novo usuário do sistema

Clica em Add e cria com:

  • Nome: Claude Code (ou descritivo do contexto, ex: Claude Code Geral)
  • Role: Admin
10
Gerar o token

Clica no System User criado → Generate New Token.

  • Seleciona o App criado no passo 02
  • Marca as permissões: ads_management e ads_read
  • Clica em Generate Token
11
Copiar o token
ATENÇÃO

O token só aparece UMA vez. Copia agora e guarda em lugar seguro. Se perder, tem que gerar outro.

Cola o token no chat do Claude quando ele pedir. Ele salva direto no .env da skill — não vaza pra outras sessões.

12
Adicionar contas de anúncios ao App

Pra cada cliente que tu vai gerenciar:

  1. BM do cliente → Usuários → Parceiros
  2. + Adicionar → cola o ID da BM dona do App
  3. Atribuir ativos → Contas de anúncios → marca a conta → Controle total

Depois, na BM dona do App: Usuários do Sistema → clica no Claude Code → Adicionar ativos → Contas de anúncios → marca as novas contas dos clientes → Controle total.

Validar que tá funcionando

De volta ao chat do Claude:

> /cockpit-meta-ads listar contas ✓ Conectado como: [Seu Nome] ✓ 4 contas de anúncio encontradas: - act_191737889662177 (Hypertech) - act_1375975899342771 (Liso Ideal) - act_1725538527656776 (EV Cosméticos) - act_9931942036905269 (CA02)

Apareceu lista? Pronto. Cockpit Meta-Ads configurado.

Próxima conta? Não precisa refazer setup

Pra adicionar outro cliente, basta repetir só o passo 12 (compartilhar a conta de anúncios via parceria entre BMs). Token, App e System User permanecem.
