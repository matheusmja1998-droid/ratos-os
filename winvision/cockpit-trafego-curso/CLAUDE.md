## 🔧 Setup técnico das gravações

**OBS:**
- Perfil: `Cockpit Tráfego` (importado de `winvision/obs-cockpit/Cockpit_Trafego.json`)
- Cenas: Tela + Cam, Só Cam, Só Tela, Intro Pausa
- Câmera: iPhone via Continuity Camera (formato vertical, cantos arredondados)
- Áudio: mic de lapela + filtros aplicados (noise gate, compressor, +6dB)

**Fluxo de gravação:**
1. Gravar bruto no OBS → salva em `02-gravacoes/aula-XX/`
2. Editar (CapCut/Descript) → salva versão `03-edicao/aula-XX/`
3. Finalizar MP4 → salva em `04-finais/aula-XX.mp4`
4. Subir no Cakto
