# 🎬 AULA 1 — Tour Claude Code + VSCode

**Duração:** ~10 min
**Tipo:** Conceitual (mais fala, menos mostra)
**Cena OBS:** Cockpit - Tela + Cam

---

## 🪝 Abertura (30s) — Cena: Só Cam

> "Antes de tu instalar nada, deixa eu te mostrar o que tu vai usar todo dia. Se tu pular essa aula, tu vai abrir o Claude Code, ver um chat parecido com o do ChatGPT e achar que é a mesma coisa. Não é. Em 10 minutos eu te mostro a diferença."

---

## 📋 Conteúdo da aula

### Bloco 1 — O que é o Claude Code (1 min) — Cena: Tela + Cam

**Fala:**
> "Claude Code não é chatbot. É um agente que **acessa pastas e arquivos do teu computador**. A diferença pro ChatGPT é simples: o ChatGPT responde. O Claude Code **executa**. Ele cria arquivo, edita arquivo, lê arquivo, roda comando. Ele opera o teu Mac, não só conversa contigo."

**Mostra na tela:** janela do Claude Code aberta no VS Code (qualquer projeto).

---

### Bloco 2 — Como ele organiza o trabalho (2 min) — MOSTRAR

**Fala:**
> "Olha aqui ó. Tu vê essa árvore de pastas na lateral esquerda? Cada pasta é um contexto separado. No meu caso, eu tenho uma pasta por cliente. Caio aqui, Hypertech aqui, EV ali. Quando eu abro o Claude Code dentro da pasta do Caio, ele já sabe que eu tô falando do Caio. Eu não preciso explicar quem é o Caio toda vez."

**O que fazer:**
1. Abre o VS Code com a pasta `Ratos OS`
2. Mostra a árvore de pastas
3. Aponta com o mouse: clientes, skills, contexto

---

### Bloco 3 — CLAUDE.md, o cérebro do projeto (1,5 min) — MOSTRAR

**Fala:**
> "Esse arquivo aqui, ó: `CLAUDE.md`. Esse é o cérebro de cada pasta. Toda vez que eu abro uma conversa com o Claude dentro dessa pasta, ele lê esse arquivo automaticamente. Aqui dentro tem dados do cliente, regras de copy, o que a gente já fez, o que tá rolando agora. É tipo um briefing permanente que tu não precisa repetir nunca mais."

**O que fazer:**
1. Abre um `CLAUDE.md` de exemplo (qualquer cliente)
2. Mostra o conteúdo: avatar, regras, histórico

**Analogia rápida:** "É tipo o briefing que o cliente te manda no primeiro dia. Mas em vez de tu reler toda hora, a IA leu por ti uma vez e nunca mais esqueceu."

---

### Bloco 4 — Sistema de memória (1 min)

**Fala:**
> "Outra coisa que ele tem: memória. Quando tu corrige o Claude, ele aprende. Por exemplo, eu uma vez disse 'nunca usa travessão'. Ele salvou. Hoje, em qualquer projeto, ele não usa travessão. Tem memória global (que vale pra tudo) e memória por projeto (que vale só ali). Tu não precisa repetir tudo toda vez que abre o chat."

**O que fazer:** (opcional) Mostra um arquivo `memory.md` ou um aprendizado salvo.

---

### Bloco 5 — Skills, o pulo do gato (2,5 min) — MOSTRAR

**Fala:**
> "Agora a parte que muda o jogo: **skills**. Skill é uma habilidade treinada. Cada skill tem um arquivo SKILL.md que explica o que ela faz e como. Olha aqui ó."

**O que fazer:**
1. Abre a pasta `.claude/skills/`
2. Mostra as skills do Cockpit listadas
3. Aponta especificamente: **cockpit-meta-ads** e **cockpit-orquestradora-anuncios**

**Continua falando:**
> "Tu vai instalar essas duas. A **cockpit-meta-ads** é a executora, quem aperta o botão na conta do Meta. A **cockpit-orquestradora-anuncios** é o cérebro, quem analisa, gera diagnóstico, fala o que fazer. E o melhor: o Claude decide sozinho qual usar. Eu não preciso digitar `/cockpit-meta-ads`. Eu falo `faz o diagnóstico do Caio` e ele dispara a orquestradora automaticamente."

---

## 📝 Dicas

1. **Não decora.** Lê o roteiro 2x antes, depois fala com tuas palavras.
2. **Pausa no final de cada bloco.** Dá 2s de silêncio (facilita corte).
3. **Quando errar:** pisca 2x, conta 1s, repete a frase. Não para a gravação.
4. **Roteiro no celular/iPad**, não no Mac que tá gravando.
5. **Olha pra câmera** 70% do tempo, mesmo mostrando tela.
